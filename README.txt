ЗАГРУЗКА НА GITHUB PAGES

1. Распакуйте ZIP.
2. В репозитории удалите старые index.html, maket.png и старые photo-* файлы, если они есть.
3. Выделите ВСЕ файлы из этой папки и перетащите их в Add file → Upload files.
4. Нажмите Commit changes.
5. Подождите 1–3 минуты и обновите GitHub Pages.

Важно: photo-01...photo-49 — это исходные растровые элементы, извлеченные напрямую из SVG без пересжатия.
